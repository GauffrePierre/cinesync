# File map (AI reference)

One line per file: responsibility → key symbols. Paths relative to repo root.

## Root
- `Dockerfile` → 2 stages: node builds `frontend/dist` → python:3.12-slim serves API + SPA (`/app/static`); runs as `PUID:PGID` via `docker/entrypoint.sh` (drops root, data dir 700 / files 600); `FORWARDED_ALLOW_IPS` default `127.0.0.1,172.16.0.0/12`.
- `docker-compose.yml` → single service `cinesync`, port `${CINESYNC_BIND}:${CINESYNC_PORT}:8000`, volume `${DATA_PATH}:/app/data`. Optional untracked `docker-compose.override.yml` for extra binds (proxy container).
- `.env.example` → all env vars (see `backend/app/config.py`).
- `.github/workflows/ci.yml` → on push to main / pull request touching `backend/` or `frontend/`: pytest, `npm run check:i18n` (`frontend/scripts/check-i18n.mjs`), vite build; single job, cancelled by a newer push.
- `.github/workflows/docker.yml` → on tag `v*.*.*`/manual: pytest + vite build, then multi-arch image to `ghcr.io/<owner>/cinesync` (actions pinned by SHA). `.github/dependabot.yml`, `.github/FUNDING.yml`.
- `unraid/syncine.xml` → Unraid template (TemplateURL brute GitHub) ; `ca_profile.xml` → profil du dépôt pour Community Applications. `e2e/` (tests navigateur Playwright : `conftest.py` démarre un serveur neuf, `test_app.py`) · `CHANGELOG.md` (une section par version → page GitHub Release, `.github/workflows/release.yml`), `SECURITY.md`, `LICENSE` (AGPL-3.0), `README.md` (FR) / `README.en.md`.
- `docs/wiki/` human dev wiki · `docs/guides/{fr,en}/` user starter guides · `docs/ai/` this folder · `docs/screenshots/` README images (demo data).

## Backend `backend/app/`
- `__init__.py` → `__version__` (single source).
- `main.py` → FastAPI app; middlewares: gzip, optional CORS (`CORS_ORIGINS`), security headers + CSP, HSTS only on `PUBLIC_URL` host, HTTP→HTTPS redirect on public host, same-origin check for unsafe methods; mounts routers (`auth` public, others `Depends(require_ready)`); `/api/health`; SPA static route (path-traversal safe, cache headers).
- `config.py` → `Config` (pydantic-settings): `data_dir`, `static_dir`, `cinesync_mode`, `api_docs`, `hsts_seconds`, `public_url`, `cors_origins`, `notification_interval_hours`, `log_level`.
- `database.py` → engine (SQLite WAL), `SessionLocal`, `Base`, `UserScoped` mixin, `bind_user`, ORM events (`_scope_to_user`, `_assign_user`), `_add_missing_columns`, `_rebuild_for_users` (`_REBUILD_FOR_USERS`), `init_db` (creates admin id 1, setup code), `setup_required`.
- `scheduler.py` → APScheduler jobs: health 15 min, `pull_library` 30 min (sync + history import, per user), availability (24 h), new episodes (6 h); `for_each_user(job)`, `availability_one`, `episodes_one`.
- `models/` → `user.py` (`User`, `AuthSession`), `user_settings.py` (`UserSettings`: per-user row; global fields on row 1), `media_state.py` (`MediaState`: per-title merged state, `*_sources` JSON), `swipe_history.py`, `watch_event.py` (history for stats; plex events carry `plex_account_id`), `notification.py`, `media_request.py`, `push_subscription.py` (devices subscribed to Web Push), `suggestion_feedback.py` (more / less like this), `suggestion_shown.py` (suggestions already shown). All personal ones inherit `UserScoped`. Secret columns use `EncryptedString` (`services/crypto.py`).
- `schemas/settings.py` → `SettingsOut.from_model(s, admin)` (masks secrets, hides server URLs from members), `SettingsUpdate`, `SECRET_FIELDS`. `schemas/media.py`.
- `routers/` → `auth` (setup, login, 2FA, logout, password, profile), `auth_external` (sign-in with Plex [PIN bound to the browser] or Jellyfin / Emby [password or Quick Connect]), `admin` (users, allowed Plex / Jellyfin accounts, shared watchlists), `admin_server` (media server dashboards, scan, stats — full admins), `admin_backups` (database backups — full admins), `user` (settings, status, tests, meta, stats), `media` (aggregated title page, highlights, suggestions), `library` (state keys, watchlist/watched/rating/like/dislike, sync), `tmdb`, `trakt` (device code + PKCE OAuth, reads), `plex` (library, images, server connection [admin], watch-link), `episodes`, `tonight`, `swipe`, `search`, `notifications`, `requests`, `cinema`, `justwatch`, `letterboxd`, `seerr`, `news`, `jellyfin` (server connection [full admin], account link by password or Quick Connect, image relay), `push` (device subscribe / unsubscribe / test). Endpoint list: `docs/ai/api.md`.
- `services/`
  - `context.py` → `Ctx` (db, `EffectiveSettings`, user) with cached clients `tmdb`, `plex` (read; own token, or the server's for admins only — `None` for members without Plex), `plex_own` (member's own token: watched/progress/writes), `plex_admin`, `plex_account`, `trakt`, `trakt_app`, `seerr`, `letterboxd`, `justwatch`; `GLOBAL_FIELDS`, `SHARED_ID=1`, `settings_for`, `ctx_for` (scheduler), `get_ctx`, `public_base_url`.
  - `auth.py` → scrypt hashing, `RateLimiter` (keys `pair:`, `ip:`, `user:`, `all:`), sessions (`open_session`, `close_session`, `close_all_sessions`, `session_user`), deps `current_user`, `require_ready`, `require_admin`, `require_server_mode`, `personal_mode`.
  - `backup.py` → SQLite online backup → gzip in `data/backups` (600), `rotate`, `run_automatic` (scheduler `db_backup`, hourly check, 23 h), `path_of` (name whitelist).
  - `push.py` → Web Push: VAPID key `data/vapid.pem`, `encrypt` (http-ece aes128gcm), `_vapid_header` (ES256 JWT), `allowed_endpoint` (push hosts whitelist), session events `after_flush`/`after_commit` → `deliver` in a worker thread for every new Notification.
  - `messages.py` → notification templates: French template = key (stored as `msg_key` + `msg_params`), English for push; frontend translates the same keys.
  - `totp.py` → 2FA: RFC 6238 codes (`code_at`, `verify` with replay counter), `provisioning_uri`, `qr_svg` (segno), recovery codes (sha256, single use).
  - `library_sync.py` → `pull` (collect + merge + optional two-way), `act` (apply one action everywhere), `_two_way` (safeguards), `preview`, `state_of`, `get_row`; per-user `_last_pull`, `_pull_locks`, `_failed_once`.
  - `history.py` → imports (Plex server-wide with account→user mapping, Trakt, Letterboxd), `assign_plex_events`, `stats`, `events_between`.
  - `health.py` → service tests, state per (user|global, service), down notifications (`GLOBAL_SERVICES` → admins).
  - Clients: `tmdb_client.py`, `trakt_client.py` (token refresh, pagination `_get_all`), `plex_client.py` (server; cache per token), `plex_account.py` (plex.tv: watchlist, scrobble, ratings, `watch_url`), `plex_auth.py` (PIN, resources, `server_users`, `account_info`), `seerr_client.py`, `letterboxd_client.py` (RSS), `justwatch_client.py` (unofficial GraphQL), `allocine_client.py` (unofficial, FR/DE/ES/TR/MX).
  - `news.py` → film news catalog (`CATALOG`, `DEFAULTS`), feed parsing to plain text, YouTube (RSS, API fallback), `resolve` (custom sources), image relay (`proxied`, `valid_signature`, `image`, disk cache). `safe_fetch.py` (SSRF-safe GET). `secret.py` (`server_secret()` in data dir).
  - `crypto.py` → at-rest encryption of tokens / API keys / TOTP secrets: `EncryptedString` column type (AES-256-GCM, key derived from `secret.server_secret()`, `enc1:` prefix), `encrypt`, `decrypt` (wrong key → empty string, never an error). Plain values of older databases are encrypted at startup (`database._encrypt_secrets`).
  - Suggestions: `suggestions.py` (`signals`, `seeds` [20 strongest + 20 drawn daily], `_prior` [recent / known / well rated], `suggestions`, `excluded_keys`, `seen_keys`, `record_shown`), `taste.py` (taste profile from loved titles: `features` [cached a week], `profile`, `affinity` → score multiplier and displayed reason), `family.py` (suggestions between accounts sharing their tastes: `partners`, `family_loved`, `common_watchlist`, `together`), `habits.py` (evening habits by weekday, nearly finished series, for Tonight).
  - Jellyfin / Emby: `jellyfin_client.py` (library, images, users, sessions, authentication, Quick Connect calls), `quick_connect.py` (pending Quick Connect requests: the secret stays on the server).
  - `sorting.py` (sorts shared by Library, Watchlist and Tonight), `tvmaze.py` (exact airing times, public API), `clock.py` (`utcnow`, naive UTC like the DateTime columns).
  - Others: `cache.py` (TTL cache, keys start with service name), `http.py` (shared httpx client, `USER_AGENT`), `errors.py` (`ServiceError`, `NotConfigured`), `enrich.py` (providers/plex badges, `refs_to_items`, `plex_keys`), `suggestions.py`, `mock_data.py` (demo data without TMDB key).
- `backend/tests/` → `conftest.py` (temp DB, fakes), `test_accounts.py` (auth, isolation, editions; helpers `client`, `setup_admin`, `add_member`, `login`, `member`, `link_plex`), `test_security_regressions.py` (one test per fixed security flaw: isolation, rate limits, bounded inputs, admin access, encryption at rest), `test_two_factor.py`, `test_jellyfin.py`, `test_push.py`, `test_backup.py`, `test_library_sync.py`, `test_admin_plex.py`, `test_plex_links.py`, `test_news.py` (SSRF, image relay), `test_suggestions.py`, `test_family.py`, `test_family_watchlists.py`, `test_habits.py`, `test_seen.py`, `test_sorting.py`, `test_airing.py`, `test_half_stars.py`, `test_notify_triggers.py`, `test_profile_stats.py`.
