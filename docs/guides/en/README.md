# Getting started guides

Pick the guide that matches your situation. *[Version française](../fr/README.md)*

| Your situation | Guide |
|---|---|
| I'm installing SynCiné **just for me** | [Personal edition](personal-edition.md) |
| I'm installing SynCiné **for my family** and managing it | [Server edition: administrator](server-admin.md) |
| I was invited to someone's SynCiné, **with my Plex account** | [Family member](server-member.md#with-a-plex-account) |
| I was invited **with my Jellyfin or Emby account** | [Family member](server-member.md#with-a-jellyfin-or-emby-account) |
| I was invited **without a Plex account** (username and password) | [Family member](server-member.md#without-a-plex-account) |

Installation itself is covered in the [installation guide](installation.md): Docker Compose, Unraid, TrueNAS, Proxmox, OpenMediaVault.
