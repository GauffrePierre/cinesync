# Guides de démarrage

Choisis le guide qui correspond à ta situation. *[English version](../en/README.md)*

| Ta situation | Guide |
|---|---|
| J'installe SynCiné **pour moi seul** | [Version personnelle](version-personnelle.md) |
| J'installe SynCiné **pour ma famille** et je l'administre | [Version serveur : administrateur](serveur-admin.md) |
| On m'a invité sur le SynCiné de quelqu'un, **avec mon compte Plex** | [Membre de la famille](serveur-membre.md#avec-un-compte-plex) |
| On m'a invité, **avec mon compte Jellyfin ou Emby** | [Membre de la famille](serveur-membre.md#avec-un-compte-jellyfin-ou-emby) |
| On m'a invité, **sans compte Plex** (identifiant et mot de passe) | [Membre de la famille](serveur-membre.md#sans-compte-plex) |

L'installation elle-même est décrite dans le [guide d'installation](installation.md) : Docker Compose, Unraid, TrueNAS, Proxmox, OpenMediaVault.
